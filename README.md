# Лабораторная работа №1. Основы HTML и структура веб-страницы

## Описание

Учебный проект — веб-страница «О себе», созданная в рамках лабораторной работы №1 по курсу «web-технологии».

Вариант 16: Тема «Предприниматель и стартапер».

## Цель работы

Освоить базовую структуру HTML-документа, семантические теги, работу с текстом, списками, ссылками, изображениями и формами.

## Использованные технологии

- HTML5 (семантическая разметка)
- CSS3 (встроенные стили, оранжево-белая цветовая гамма)
